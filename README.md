# Care Connect

Build a premium, production-quality healthcare startup website using React (Vite), Tailwind CSS, React Router, Framer Motion, and Lucide React icons.

The website represents an MBBS General Physician.

Design style:

- Modern, premium, minimal

- White background

- Primary color: #2563EB

- Secondary color: #14B8A6

- Background: #F8FAFC

- Cards: White

- Text: #1E293B

- Body text: #64748B

- Rounded corners (20–24px)

- Soft shadows

- Plenty of whitespace

- Responsive (mobile, tablet, desktop)

- Typography: Poppins for headings, Inter for body

Include smooth Framer Motion animations:

- Hero fade and slide-up

- Floating doctor illustration

- Fade-in sections on scroll

- Staggered card animations

- Hover lift and scale effects

- Count-up statistics

- Sticky navbar with blur on scroll

- Smooth page transitions
